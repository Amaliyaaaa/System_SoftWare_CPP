## Примененные технологии

В рамках разработки подпрограмм для шести лабораторных внутри единого проекта CMake были изучены следующие темы:

1. Представление данных в приложениях системного назначения: бинарное кодирование, двоичная арифметика, имитация дампа памяти при работе процессора с переменными
Формулировка задания: 
- Разработать подпрограммы (функции) на любом языке высокого уровня, реализующие перевод чисел из десятичной системы в двоичную (без использования стандартных средств языка программирования), двоичное кодирование отрицательных чисел, двоичное сложение и вычитание. 
- Применить разработанные функции для вычисления значения выражения в соответствии с индивидуальным заданием (A, B, C, D принадлежит диапазону включительно -32767; 32767). 
- Вывести на экран значения A, B, C, D, X в десятичном и двоичном виде, а также обеспечить имитацию вывода на экран дампа памяти с хранящимися в последовательных ячейках значениями этих переменных. Значения относительного адреса (сегмента и смещения), где хранятся переменные, вводят-ся пользователем вручную с клавиатуры. Определить абсолютные адреса каждой переменной.


2. Массивы и матрицы: указатели, динамические объекты языка С, экономия памяти при работе с массивами
Формулировка задания:
Для разряженной матрицы целых чисел в соответствии с индивидуальным заданием создать модуль доступа к ней, в котором обеспечить экономию памяти при размещении данных. Все нулевые элементы размещены в шахматном порядке, начиная со 2-го элемента 1-й строки


3. Работа с символьными строками без использования встроенных функций и библиотек для работы со строками
Формулировка задания:
Функция Pos(s,s1)
Назначение: поиск первого вхождения подстроки s1 в строку s (аналогичная функция C — strstr).


4. Структуры, объединения, перечисления, битовые поля: то есть для структуры (записная книжка), которую я должна была создать, нужно было применить битовые поля и создать несколько функций для работы с ними. Это наверное самая объемная работа, мне так показалось, по крайней мере
Формулировка задания:
- Описать структуру «Записная книжка». Анкетные данные, адреса, телефоны, место работы или учебы, должность знакомых, коллег и родственников, характер знакомства, деловые качества и так далее. Автоматическое формирование поздравления с днем рождения (по текущей дате).
Поиск по фамилии.
Дату рождения реализовать с помощью битового поля, характер знакомства  с помощью перечисления.
- Используя битовые операции проверить, кратно ли шестнадцати число А.


5. Использование языка ассемблера в программах на языке С: здесь был отдельно написан код на ассемблере и отдельно на C++ в двух файликах. Пришлось на этом этапе перевести компиляцию для отладки с х64 на х86. Об особенностях запуска в следующем разделе.
Формулировка задания:
- Даны целые числа а, b и c. Вычислить значение выражения 6a-(3b-2c)
- Поменять местами второй и третий элемент массива (нумерация элементов ведется с 0)

6. Разработка и использование библиотек динамической компоновки (DLL). Здесь помимо основного файла программы (в который мы импортировали нашу собственноручно разработанную библиотеку FuzzyRelations), создана отдельная папка dll, к файлам которой мы и обращаемся.
Формулировка задания:
- Реализовать в динамически подключаемой библиотеке функционал со-гласно варианту задания. При необходимости предусмотреть проверку на не-возможность выполнения определенной операции, а также возможную обработку исключений. Разработать приложение, демонстрирующее работу созданной DLL. 
- Операции с нечеткими отношениями: максиминная композиция, минимаксная композиция, максмультипликативная композиция. (вот тут самое сложное это понять что это такое...)

### Как протестировать:

Как разработчик вы можете скачать себе все файлы этого проекта, собрать решение и запустить, используя, например, visual studio 2022. Предварительно:
1. В Visual Studio Installer необходимо выбрать рабочую нагрузку Разработка классических приложений на C++ (Desktop development with C++).
2. Убедитесь, что установлены компоненты:
- MSVC v143 — VS 2022 C++ x64/x86 build tools
- C++ CMake tools for Windows
- Windows 10 или 11 SDK
- Ninja	
- Microsoft Macro Assembler (MASM)
2. Сборка должна быть под х86, не х64! Это необходимо для работы с ассемблером (5 лабораторная)
3. папку out я выгрузила вместе с остальными файлами проекта, но она вам не нужна, ее содержимое можно снести. при сборке проекта все необходимое там волшебным образом появится.

Для не разработчиков залью файл exe (без вирусов)), его можно будет просто скачать и запустить.
